# 自制组件说明

## local-ai-router

调用 `D:\CodexLocalAI` 中的本地 DeepSeek/Qwen 模型完成代码初稿、机械性拆分、批量提取和归纳，并把精简结果交回 Codex复核。它不替代最终审查，也不应把本地项目或凭据发送到外部服务。

## intent-refiner

将口语化、零散或多轮补充的需求整理为可执行目标。只在关键歧义会显著改变结果时提问；需求明确时直接继续完成原任务。

## publish-custom-plugins.ps1

从固定 D 盘路径读取白名单内的自制插件，先在临时目录完成结构与敏感信息检查，再同步到仓库。正式模式会生成 Git 提交，并在指定 `-Push` 时推送到 GitHub。
